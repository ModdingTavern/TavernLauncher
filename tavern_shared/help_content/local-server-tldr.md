# Setting up a local server for yourself (TLDR)

## Getting the files for The Modding Tavern

Get the latest version here: <br>
<https://github.com/ModdingTavern/TavernLauncher/releases>

Download: <br>
`TavernLauncher-Server-vX.Y.Z.zip` <br>

Right click it and extract it.

## Running TavernLauncher (Server)

Open the .exe in the extracted folder. <br>
Say "Yes" or "Allow" to any firewall related questions.

## Pointing TavernLauncher to your game

Click the "Browse" button and select: <br>
`C:\Games\Alta\A Township Tale\A Township Tale.exe`

If you installed the game in another directory, point it to the .exe in that folder!

## Patching the game

If you already did this on the client launcher, this section isn't needed again.
If this is the first time:

Click "Patch".

Second, click "Mods". <br>
Click "Install" on each of the following in order: <br>
- MelonLoader <br>
- TavernLib <br>
- TavernVoice

## Essentials

### Game Port

Leave this on 1757.

### Server Settings

Click the "Settings" button to start configuring your server.
Fill in: <br>
- Server Name <br>
- Auto-reboot (optional, but recommended)

### Players

Click this button.
If you do not care about setting admin rights on your account and just want to play singleplayer, skip this whole section.

#### Players

If you want to give yourself admin or flycam:

Set any of the following rules for your username: <br>
- admin <br>
- mod <br>
- fly

## Starting Your Server

Click "Open Server" button to start up your own server.
Say "Yes" or "Allow" to any firewall related questions.

## Conclusion

All done, your server is now ready and running.
